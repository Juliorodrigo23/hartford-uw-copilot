# Insurance underwriter audit — November 18, 2026

Scope: current GitHub source, the production Vercel demo, Cloud Run configuration and error logs, retrieval and model artifacts from the last successful build, the agent graph and model clients, input/authentication boundaries, streaming/UI behavior, ingestion, ML training, evaluation, dependencies, and deployment reproducibility. This is an engineering audit; the model-quality numbers below are historical, not newly measured quality improvements.

## Failures identified and repaired

| Finding | Evidence | Repair |
| --- | --- | --- |
| Retired Gemini models and wrong endpoint | Production generation logged Vertex 404 for `gemini-2.5-pro` in `us-central1`. Live probes succeeded for the replacements globally and failed regionally. | Set drafting to `gemini-3.8-flash`, parsing/Gemini critique to `gemini-3.5-flash-lite`, and `GCP_LOCATION=global`. Keep Cloud Run itself in `us-central1`. Update deployment defaults and visible model labels. |
| Deployment still scaled to zero | Neither a service nor revision minimum was present in the running configuration. | Set both minimums to one. Retain startup CPU boost and retrieval preloading. Add `/ready` and a startup probe that gates traffic until warmup completes. Warm instances incur ongoing idle charges. |
| Invalid OpenAI credential | The production secret and saved project credential both returned HTTP 401 `invalid_api_key`. | Routing is repaired, but restoring successful GPT calls requires a valid `openai-api-key` secret. No credential is included in this report or source. |
| Explicit GPT selection silently became Gemini | The critique node substituted Gemini whenever OpenAI returned no result, including explicit selections. | Substitution is allowed only in auto mode and emits a visible warning. Explicit choices stay on the requested provider; an unavailable reviewer leaves a clearly unreviewed memo. |
| Provider content blocks broke JSON extraction | A real replacement-model response contained a list of text blocks; stringifying the list produces Python representation rather than the model's JSON. | Normalize text blocks consistently in parsing, drafting, critique, and the evaluation baseline. Exclude thinking/signature fields. |
| Generation failures masqueraded as memos | `draft_memo` caught failures and returned an error document, which the rest of the graph could critique and finalize. | Emit a terminal stream error. Produce neither a recommendation nor a quality-check result from a failed draft. Bound model-call duration and retries. |
| Empty/incomplete critique could pass | `CritiqueVerdict` defaulted an empty object to pass. | Require all five finite rubric scores in range, an explicit pass field, and force failure for a low score or outstanding gap. Give reviewers evidence excerpts, not citation IDs alone. |
| Invalid recommendations defaulted to a quote | Missing/malformed structured output defaulted to `quote_with_surcharge`. | Return `data_insufficient` with zero confidence and a human-review reason. |
| Chroma initialization could race | Early production diagnostics reported `RustBindingsAPI` missing `bindings`; `lru_cache` allows concurrent cache misses during startup. | Serialize persistent-client creation and avoid probing the index from diagnostics during warmup. |
| Trace timings described completion as entry | SSE `node_enter` was derived from state updates emitted after each node completed. | Use graph task start/result events for actual node boundaries. Expose draft/critique model routes and final review status. Remove artificial token delays. |
| Interrupted streams could look complete | The browser accepted stream closure after partial text without requiring a terminal event. | Require a final/error event, clear active/pending state on termination, and distinguish unresolved or unavailable review. |
| Signing bypassed proxy input/rate checks | The direct-stream `/api/sign` route had no equivalent guard. | Share request-size, schema, and per-instance rate checks between signing and proxy routes. Reject missing signing configuration. Authenticate trace reads. |
| Vulnerable frontend dependencies | Initial `pnpm audit --prod` reported 40 advisories, including critical Next.js advisories. | Patch within Next.js 15, update PostCSS and compatible fflate versions; final production dependency audit reports zero advisories. |
| Builds could silently change dependencies | Docker fell back from frozen installation to unlocked resolution. | Require frozen installation. Add backend/frontend GitHub Actions checks and focused regression tests. |

## Prioritized follow-up improvements

1. **Restore and monitor independent critique.** Replace the invalid OpenAI secret, create a new Cloud Run revision to load it, and verify an explicit OpenAI run. Add a small deploy-time model-access probe and alert on authentication/model-not-found errors. Presence of a key in `/diag` does not prove validity. Track generation success, reviewer availability, provider substitution, latency, token cost, and unresolved review separately.

2. **Improve measured underwriting quality before adding more graph complexity.** The canonical July 13 export reports retrieval recall@10 33.3%, red-flag recall 11.1%, and 0.2 prohibited-claim matches per case across only five task cases. The latter is a term-based count divided by cases, not an exhaustive probability that a memo hallucinates. The README previously showed different retrieval and red-flag figures; it now matches the tracked export. Expand the labeled set, add paraphrase/negation/numeric-consistency cases, report uncertainty and case coverage, and compare the new models against the existing baseline. The existing 80% pairwise win rate coexists with lower average agent rubric scores; neither metric alone establishes improvement. Do not present the saved metrics as results from the migrated models.

3. **Evaluate calibration on data the calibrator has not seen.** `backend/app/ml/train_xgb.py` fits isotonic calibration to out-of-fold model predictions, then reports calibrated performance on those same calibration rows. The base model predictions are out of fold, but this does not make the calibrator's reported performance held out. Use nested/group-aware calibration splits and a time-held-out test set. Preserve the synthetic-training disclosure and avoid treating the synthetic model's confidence interval as validated real-world coverage.

4. **Make persistence match the durability claims.** SQLite lives on the Cloud Run container filesystem. It can survive worker restarts within the same container; it is not durable across instance replacement and is not shared across instances. Use managed Postgres or another shared LangGraph checkpointer before scaling beyond the current single-instance demo. Add retention/cleanup and stop tracking runtime checkpoint/WAL files in Git.

5. **Harden identifier and evidence boundaries.** `safer_lookup` builds a cache path from the supplied DOT string; validate a numeric DOT before any filesystem access. Add cache freshness/source timestamps, preserve distinctions between unknown and zero safety measures, and explicitly bound duplicate/missing loss years. Treat broker text and retrieved documents as untrusted evidence in prompts. Add deterministic checks for citation existence, numerical consistency, and disposition agreement alongside model critique.

6. **Reduce retrieval startup and resource cost through measurement.** BGE Large, Torch, Chroma, and the cross-encoder make the image and warm process heavy. Benchmark a smaller embedding model, CPU-only runtime dependencies, cached query embeddings, and vector-store separation against the labeled retrieval set. Rebuild the index whenever the embedding model changes. Keep warmup/readiness telemetry and measure warm-request p50/p95 latency; a minimum instance does not prevent all cold starts during deployments or replacement.

7. **Use durable abuse/cost controls if this grows beyond a portfolio demo.** Frontend/backend limits remain in memory per process/instance and are not a global quota. Use a shared limiter and a daily model-spend budget. Consider scoped one-time request tokens: the current timestamped HMAC permits replay of an identical signed request within its five-minute validity window.

8. **Tighten input/feature and export contracts.** Optional columns in `backend/app/ml/features.py` currently use scalar defaults followed by `.astype`, which fails when a column is absent. Replace defaults with index-aligned Series and add missing-column tests. Version the model/features/corpus/export schemas together. Add artifact manifests and data-freshness checks so fresh checkouts and isolated frontend builds cannot quietly use mismatched data. The preserved production artifacts were recovered from the previous successful Cloud Build source rather than regenerated during this repair.

9. **Finish the SDK and UI maintenance incrementally.** The installed `ChatVertexAI` integration emits a deprecation warning; migrate to the supported Google integration in a separate evaluated change. Keep the graph/client interface stable and rerun model-response tests. The demo currently emits memo text after drafting completes; the trace is live, but this is not provider-token streaming. For true incremental drafts, connect model stream events with a clear redraft boundary. Improve per-message citation ownership and associate saved traces with a source/model version. Migrate deprecated `next lint` before moving to Next.js 16.

## Validation

- Backend: 65 tests pass, covering both provider selections, auto fallback, failed generation, invalid verdicts, real SSE node ordering, authentication, startup readiness, and concurrent client initialization.
- Frontend: eight stream/signing regression tests pass; TypeScript, lint, and production build pass.
- Dependency scan: zero known advisories in the final frontend production dependency scan. This is not a complete backend/transitive/native dependency security assessment.
- Live provider probes: Gemini 3.8 Flash and Gemini 3.5 Flash Lite succeed globally through both REST and the application's LangChain client. Regional Gemini 3.8 Flash returns 404. OpenAI's existing credential returns 401.
- Deployment and end-to-end smoke results are recorded in the delivery notes after rollout. Successful OpenAI generation/review cannot be claimed until a valid credential is supplied.

No new actuarial training, quality-evaluation scores, historical showcase trace, or carrier underwriting decisions were fabricated as part of this repair.
